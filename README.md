# RoboBuilder project page

Project page for **RoboBuilder: Agentic Robot Co-Design with Real-world Video Feedback in the Loop**
(Ghadi Nehme, Dahyun Nam, Akshay Govind Srinivasan, Faez Ahmed; MIT).

Live at https://ghadinehme.com/robobuilder.github.io/

- `index.html`: the page (static, no build step). Preview with `python3 -m http.server` in this folder.
- `static/`: styles, scripts, icons. `assets/`: web-encoded videos (H.264), images, paper figures and `assets/js/data.js`
  (explorer and all-in-one data, so the page also works when opened from disk).
